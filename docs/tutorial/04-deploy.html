Deploy to Streamlit-in-Snowflake

Create the git-connected Streamlit app on container runtime. Three SQL statements, one shell command, zero file uploads.

Deploy: workspace-native approach

Option A — CLI (scripts/30_deploy.sh)

snow streamlit deploy reads app/snowflake.yml for the compute pool, runtime, and EAI settings, then uploads your local app/ files to a Snowflake stage and creates/replaces the STREAMLIT object.

bash — after scripts/10_setup.sh
scripts/30_deploy.sh -c oregon-sedemo
# Equivalent to:
snow streamlit deploy -c oregon-sedemo -p app/ --replace

Option B — Snowsight Workspace

  1. Open Snowsight → Workspaces → New workspace
  2. Browse to app/streamlit_app.py and press Run for a private dev preview
  3. Press Deploy — Snowsight reads app/snowflake.yml for settings
💡
Both options deploy the same STREAMLIT object in the same database/schema. CI/CD uses Option A (30_deploy.sh). Interactive development can use either — the workspace provides a live preview before publishing.

app/snowflake.yml

The snowflake.yml in the app/ directory declares all deployment settings. Both the workspace Deploy button and snow streamlit deploy read it.

app/snowflake.yml
definition_version: 2
entities:
  ingest_console:
    type: streamlit
    identifier:
      name: INGEST_CONSOLE
      schema: GIT_SIS
      database: SNOWFLAKE_LEARNING_DB
    title: "Ingestion Ops Console"
    query_warehouse: COMPUTE_WH
    compute_pool: SYSTEM_COMPUTE_POOL_CPU
    runtime_name: SYSTEM$ST_CONTAINER_RUNTIME_PY3_11
    main_file: streamlit_app.py
    external_access_integrations:
      - PYPI_ACCESS_INTEGRATION
    artifacts:
      - streamlit_app.py
      - pyproject.toml
      - lib/config.py
      - lib/ingest.py
      - lib/session.py
      - pages/1_run_history.py
      - pages/2_error_explorer.py
      - .streamlit/config.toml

Redeploy after a code change

bash — CLI deploy
git push && scripts/30_deploy.sh -c oregon-sedemo
✅
On push to main, GitHub Actions runs 30_deploy.sh automatically — see Chapter 5 (CI/CD). You can also redeploy from the Snowsight workspace by pressing Deploy.

Verify the deployment

bash
# Get the app URL and open it
scripts/40_verify.sh --open -c oregon-sedemo

# Or just print the URL
snow streamlit get-url -c oregon-sedemo \
  SNOWFLAKE_LEARNING_DB.GIT_SIS.INGEST_CONSOLE

Teardown (cleanup)

Two cleanup levels — choose based on what you want to preserve:

🔄

90_cleanup.sh — reset demo

Drops GIT_SIS schema, STREAMLIT, GIT REPOSITORY, and API integration. Keeps GIT_SIS_INFRA.SECRETS.GITHUB_PAT. Rebuild with 10_setup.sh && 30_deploy.sh — no PAT re-entry.

☢️

99_cleanup-infra.sh — full teardown

Also drops GIT_SIS_INFRA database and the PAT secret. Prompts for confirmation. Use --yes to skip. Only for complete decommissioning.

bash — normal reset (keeps PAT)
scripts/90_cleanup.sh -c oregon-sedemo
bash — full decommission
scripts/99_cleanup-infra.sh -c oregon-sedemo
# or without confirmation prompt:
scripts/99_cleanup-infra.sh -c oregon-sedemo --yes
