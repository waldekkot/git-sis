Key concepts

The session seam

The app runs unchanged in two environments. A single try/except in app/lib/session.py picks the right connection: get_active_session() inside Snowflake, or a CLI-built Session locally.

git-connected deploy

Snowflake clones your GitHub repo via a GIT REPOSITORY object and an API integration with a stored PAT secret. The Streamlit app is deployed directly from the cloned branch — no file uploads, no manual sync.

Three-tier dev loop

Tier 1 Unit tests — no Snowflake, zero credentials, runs in milliseconds.
Tier 2 GitHub Actions CI — unit tests + ruff on every push.
Tier 3 Integration tests — real Snowflake, isolated temp schema, run locally.

💡
Prerequisites: Python 3.11+, uv, snow CLI, a Snowflake account (SYSADMIN + ACCOUNTADMIN access), and a GitHub account.
